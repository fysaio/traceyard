# Commits and pull requests

The person who pushes a change owns it and is responsible for it.

- Commit under the repository owner's or contributor's own Git identity. Never set a tool as author or committer.
- Do not add `Co-authored-by` lines for anyone who is not a human contributor.
- Do not add "Created with", "Generated by" or similar footers, or session links, to commits, pull requests or comments.
- Do not put tool names in branch names.
