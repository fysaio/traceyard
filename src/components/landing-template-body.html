Product Contract

From intent to proof, one clear trace.

The coding agent can edit. TraceYard makes the work legible: what was intended, what changed, what ran, and what remains unknown.

INTENT [01]

What is this change trying to make true?

Pulls together the issue, request, or acceptance criteria that gave the work a purpose. When context is missing, TraceYard says so instead of inventing intent.

Provenance preserved · Never fabricated from source

IMPLEMENTATION & IMPACT [02]

What changed, and what does it touch?

Maps the diff to packages, dependencies, generated surfaces, and risk boundaries— with the exact base, candidate, or working-tree identity attached.

Typed dependency edges · Explicit unknowns

VERIFICATION [03]

What evidence is strong enough to trust?

Runs the smallest useful checks first, then the repository’s required gates. Passed, failed, blocked, and omitted are separate states—not one vague green badge.

Revision-bound receipts · Omissions always visible

Fast feedback for the loop. Revision-bound proof for the merge. Uncertainty stays visible. NO PROPRIETARY LLM REQUIRED

Structured Verification Modules

A complete loop from first thought to final merge.

01 · Two-Speed Verification

Move quickly without losing the thread.

FAST_SIGNAL_PASSED

Get a useful signal while the idea is still moving. TraceYard keeps local results fast and labels them honestly as provisional.

REQUIRED_CHECKS_PASSED

When the change is ready, rerun the declared gates against exact revisions so the evidence can travel with the merge.

Working tree Pinned commit SHA
02 · Bounded Claims

Claims your team can actually inspect.

FAST_SIGNAL_PASSED Early local checks passed; never satisfies final PR policy.
CONFIRMED_FOCUSED Exact baseline-failing assertion executed and passed on candidate.
REQUIRED_CHECKS_PASSED Every required check in repository policy passed on this exact head.
REGRESSION One or more relevant checks failed under a valid comparable environment.
REVIEW_REQUIRED Changed test inputs, policy edits, or scope class require maintainer review.
INCONCLUSIVE Scope incomplete or environment incomparable; never reports green.
BLOCKED Missing permission, service prerequisite, or unavailable required check.
03 · Agent-Native Surface

Fits the tools your team already trusts.

Local MCP & CLI

Canonical first-use loop for Codex, Claude Code, Cursor, and Copilot on an open checkout.

Repository Instructions

Versioned checkpoints and adapters keep Traceyard active without forcing manual prompts.

GitHub PR & Merge Groups

Publishes one stable status bound to exact base/candidate SHAs and pinned policy.

04 · Security & Trust Boundaries

Fast feedback, careful boundaries.

Credential-free untrusted execution

Tests and install hooks run as untrusted code isolated from reporting tokens and GitHub secrets.

Explicit local vs attested trust

Local receipts are labeled LOCAL_PROVISIONAL; checksums are never presented as signed CI attestation.

GitHub remains merge authority

Maintainers own required checks and approvals. Traceyard never auto-approves or auto-merges by default.

Untrusted test subprocess Trusted supervisor
